# Документация по данным игры «The City»

Все игровые данные хранятся в JSON-файлах в папке `data/`. Этот документ описывает структуру каждого файла и назначение полей.

---

## Технологии: два способа открыть контент

В игре есть **два разных поля**, которые связывают контент с технологиями. Их легко перепутать, но они отвечают за разные вещи:

| Поле | Где используется | Что делает |
|---|---|---|
| `tech_required` | Только **ресурсы** (`data/resources/*.json`) | Ресурс **не появляется на карте**, пока технология не изучена. При изучении технологии ресурс **спавнится** на карту. |
| `unlock_tech` | **Здания, улучшения, продукты, рецепты** | Объект **существует в данных**, но **недоступен игроку** (нельзя построить / произвести / использовать), пока технология не изучена. |

> **Правило-запоминалка:**
> - `tech_required` — «ресурс **появится в мире**»
> - `unlock_tech` — «действие **станет доступно**»

### Поведение заблокированного ресурса (`tech_required`)

1. Пока технология не изучена, ресурс **не генерируется на карте** (`map_generator.gd` пропускает его).
2. При изучении технологии ресурс **появляется на карте** (`CityData.spawn_resource_on_tech_research`).
3. В контекстном меню тайла с таким ресурсом показывается пункт **«Изучить X (наука: N)»**, который запускает исследование нужной технологии.

### Поведение недоступного объекта (`unlock_tech`)

1. Здание нельзя построить, пока технология не изучена.
2. Рецепт скрыт из списка доступных в здании.
3. Продукт не отображается как доступный на складе.
4. Улучшение (ферма, шахта и т.д.) нельзя построить на тайле.

## Справочник по файлам

### `data/technologies.json` — технологии

Корневой ключ: `technologies` (массив объектов).

| Поле | Тип | Обязательность | Описание | Пример |
|---|---|---|---|---|
| `id` | string | ✅ | Уникальный идентификатор технологии | `"farming"` |
| `name` | string | ✅ | Отображаемое название | `"Растениеводство"` |
| `era` | string | ✅ | Эпоха (см. `eras.json`) | `"ancient"` |
| `science_cost` | number | ✅ | Стоимость исследования в науке | `3.0` |
| `description` | string | ✅ | Краткое описание того, что открывает | `"Открывает все пищевые растения и позволяет строить фермы."` |
| `flavor` | string | ✅ | Лор-текст (историческая справка) | `"Первые земледельцы заметили..."` |
| `prerequisites` | array\<array\<string\>\> | ⬜ | Технологии-предшественники. **Массив массивов**: внутри каждого вложенного массива — ИЛИ (достаточно одной), между массивами — И (нужны все) | `[ [ "animal_husbandry" ] ]` — нужна одна; `[ [ "oil_making", "animal_husbandry" ] ]` — нужна одна из двух |

### `data/resources/*.json` — ресурсы на карте

Файлы:
- `resources/minerals.json` — минералы и камни
- `resources/animals.json` — животные
- `resources/plants/food_plants.json` — пищевые растения
- `resources/plants/fruit_plants.json` — плодовые растения
- `resources/plants/textile_plants.json` — технические (текстильные) культуры
- `resources/plants/flowers.json` — цветы

Корневой ключ: `resources` (массив объектов).

| Поле | Тип | Обязательность | Описание | Пример |
|---|---|---|---|---|
| `id` | string | ✅ | Уникальный идентификатор ресурса | `"wheat_field"` |
| `name` | string | ✅ | Отображаемое название | `"Пшеница"` |
| `type` | string | ✅ | Тип сущности. Для ресурсов на карте всегда `"raw"` | `"raw"` |
| `category` | string | ✅ | Категория (см. `categories.json`) | `"plants"`, `"animals"`, `"minerals"` |
| `group` | string | ✅ | Группа для бонусов за разнообразие (см. `groups.json`). Может быть пустой строкой | `"food_plants"`, `"meat_animals"`, `""` |
| `subgroup` | string | ✅ | Подгруппа для бонусов за разнообразие (см. `groups.json`). Может быть пустой строкой | `"cereals"`, `"cattle"`, `""` |
| `tech_required` | string | ⬜ | **Технология, открывающая появление ресурса на карте.** Пока не изучена — ресурс не спавнится. Отсутствует у дикоросов (`wild_food`) | `"farming"` |
| `allowed_terrains` | array\<string\> | ✅ | Типы местности, на которых ресурс может заспавниться (см. `terrains.json`) | `["plain", "hill"]` |
| `improved_by` | string \| null | ✅ | ID улучшения, которое нужно построить для добычи ресурса (см. `improvements.json`). `null` — ресурс не требует улучшения (например, дикоросы) | `"farm"`, `null` |
| `produces` | object | ✅ | Что даёт ресурс: `{ "продукт": количество }` | `{ "wheat": 1, "feed": 12 }` |
| `icon` | string | ✅ | Имя файла иконки в `icons/` | `"wheat.png"` |
| `color` | array\<number\> | ✅ | Цвет-заглушка RGB `[r, g, b]` (0–255), используется если иконка не найдена | `[218, 165, 32]` |
| `feed_consumption` | number | ⬜ | **Только для животных.** Потребление корма в единицу времени | `10` |
| `time_to_mature` | number | ⬜ | **Только для животных.** Время до взросления | `60.0` |

> **Важно:** `tech_required` используется **только** в файлах ресурсов. Для зданий, улучшений, продуктов и рецептов используется `unlock_tech`.

### `data/improvements.json` — улучшения

Улучшения — это постройки на тайлах карты (ферма, шахта, пастбище и т.д.), которые позволяют добывать ресурсы.

Корневой ключ: `improvements` (массив объектов).

| Поле | Тип | Обязательность | Описание | Пример |
|---|---|---|---|---|
| `id` | string | ✅ | Уникальный идентификатор улучшения | `"farm"` |
| `name` | string | ✅ | Отображаемое название | `"Ферма"` |
| `icon` | string | ✅ | Имя файла иконки в `icons/` | `"farm.png"` |
| `color` | array\<number\> | ✅ | Цвет-заглушка RGB `[r, g, b]` (0–255) | `[255, 255, 0]` |
| `work_cost` | number | ✅ | Стоимость постройки в труде | `8` |
| `unlock_tech` | string | ⬜ | **Технология, открывающая улучшение.** Пока не изучена — улучшение нельзя построить | `"farming"` |

### `data/crafts.json` — рецепты производства

Корневой ключ: `crafts` (массив объектов).

| Поле | Тип | Обязательность | Описание | Пример |
|---|---|---|---|---|
| `id` | string | ✅ | Уникальный идентификатор рецепта | `"bread"` |
| `name` | string | ✅ | Отображаемое название | `"Выпечка хлеба"` |
| `produced_in` | array\<string\> | ✅ | ID зданий, в которых доступен рецепт. `"*"` — доступен везде | `["bakery"]`, `["*"]` |
| `resources` | object | ✅ | Входные ресурсы: `{ "ресурс": количество }`. Ключ может начинаться с `@` — это ссылка на группу из `product_groups.json` | `{ "flour": 1 }`, `{ "@millable_grains": 1 }` |
| `result` | object | ✅ | Выходные ресурсы: `{ "ресурс": количество }` | `{ "bread": 1 }` |
| `time` | number | ✅ | Время производства | `5.0` |
| `description` | string | ⬜ | Описание рецепта | `"Создаёт набор инструментов для ремесленников"` |
| `unlock_tech` | string | ⬜ | **Технология, открывающая рецепт.** Пока не изучена — рецепт скрыт из списка | `"cheese_making"` |

> **Примечание про `@`:** если ключ в `resources` или `result` начинается с `@`, это означает «любой продукт из группы». Например, `"@millable_grains": 1` — «1 единица любой зерновой культуры из группы `millable_grains`».

### `data/products/*.json` — продукты (склад)

Файлы:
- `products/products.json` — инструменты, оружие, одежда, масло, вино
- `products/materials.json` — материалы (шкура, шерсть, мука и т.д.)
- `products/drinks.json` — напитки
- `products/fruits.json` — фрукты
- `products/construction_materials.json` — стройматериалы
- `products/other.json` — прочее (сырьё, корм, цветы)

Корневой ключ: `resources` (массив объектов).

| Поле | Тип | Обязательность | Описание | Пример |
|---|---|---|---|---|
| `id` | string | ✅ | Уникальный идентификатор продукта | `"flour"` |
| `name` | string | ✅ | Отображаемое название | `"Мука"` |
| `type` | string | ✅ | Тип сущности. Для продуктов всегда `"product"` | `"product"` |
| `category` | string | ✅ | Категория для вкладки «Ресурсы» (см. `categories.json`) | `"material"` |
| `icon` | string | ✅ | Имя файла иконки в `icons/` | `"flour.png"` |
| `unlock_tech` | string | ⬜ | **Технология, открывающая продукт.** Пока не изучена — продукт недоступен | `"weaving"` |
| `unlock_improvement` | string | ⬜ | **Только в `products/other.json`.** ID улучшения, которое открывается вместе с продуктом | `"pasture"` |

### Служебные файлы

---

#### `data/categories.json` — категории ресурсов

Корневой ключ: `categories` (массив объектов).

| Поле | Тип | Описание | Пример |
|---|---|---|---|
| `id` | string | Уникальный идентификатор категории | `"food"` |
| `name` | string | Отображаемое название | `"Еда"` |

Категории — чисто визуальное разделение для вкладки «Ресурсы» в городе. Единственное исключение: все ресурсы категории `food` складываются и учитываются как **Еда** на складе.

---

#### `data/groups.json` — группы ресурсов (для бонусов)

Корневой ключ: `groups` (массив объектов).

| Поле | Тип | Описание | Пример |
|---|---|---|---|
| `id` | string | Уникальный идентификатор группы | `"cattle"` |
| `name` | string | Отображаемое название | `"Крупный рогатый скот"` |

Группы используются механикой **бонусов за разнообразие** (см. `bonuses.json`) и при перечислении одомашненных видов. Поля `group` и `subgroup` в ресурсах ссылаются на эти ID.

> **Не путать с `product_groups.json`!** Здесь группы для бонусов, там — для подстановки в рецепты.

---

#### `data/product_groups.json` — группы продуктов (для рецептов)

Корневой ключ: `product_groups` (массив объектов).

| Поле | Тип | Описание | Пример |
|---|---|---|---|
| `id` | string | Уникальный идентификатор группы | `"millable_grains"` |
| `name` | string | Отображаемое название | `"Зерновые культуры"` |
| `products` | array\<string\> | ID продуктов, входящих в группу | `["wheat", "rye", "barley"]` |

Группы используются в рецептах (`crafts.json`) для подстановки: ключ `"@millable_grains"` в `resources` означает «любой продукт из этой группы».

> **Не путать с `groups.json`!** Здесь группы для подстановки в рецепты, там — для бонусов за разнообразие.

#### `data/terrains.json` — типы местности

Корневой ключ: `terrains` (массив объектов).

| Поле | Тип | Описание | Пример |
|---|---|---|---|
| `id` | string | Уникальный идентификатор местности | `"plain"` |
| `name` | string | Отображаемое название | `"Равнина"` |
| `color` | array\<number\> | Цвет-заглушка RGB `[r, g, b]` (0–255) | `[144, 238, 144]` |
| `move_cost` | number | Стоимость перемещения | `1` |
| `expansion_cost` | number | Стоимость расширения влияния | `50` |

---

#### `data/bonuses.json` — бонусы за разнообразие

Корневые ключи: `group_bonuses` и `subgroup_bonuses` (массивы объектов).

**`group_bonuses`** — бонусы за количество подгрупп в группе:

| Поле | Тип | Описание | Пример |
|---|---|---|---|
| `group_id` | string | ID группы (см. `groups.json`) | `"meat_animals"` |
| `bonus_type` | string | Тип бонуса | `"happiness"` |
| `tiers` | array\<object\> | Пороги бонуса | см. ниже |

**`subgroup_bonuses`** — бонусы за количество видов в подгруппе:

| Поле | Тип | Описание | Пример |
|---|---|---|---|
| `subgroup_id` | string | ID подгруппы (см. `groups.json`) | `"cattle"` |
| `bonus_type` | string | Тип бонуса | `"happiness"` |
| `tiers` | array\<object\> | Пороги бонуса | см. ниже |

**Объект `tiers`:**

| Поле | Тип | Описание | Пример |
|---|---|---|---|
| `min_subgroups` / `min_species` | number | Минимальное количество подгрупп (для `group_bonuses`) или видов (для `subgroup_bonuses`) | `3` |
| `value` | number | Величина бонуса | `10` |
